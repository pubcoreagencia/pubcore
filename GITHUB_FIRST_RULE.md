# Regra Permanente — GitHub First

Antes de construir do zero qualquer solução técnica relevante, pesquise primeiro projetos, bibliotecas e implementações existentes no GitHub.

Processo obrigatório: pesquisar → comparar maturidade, manutenção, arquitetura, licença e segurança → decidir entre reutilizar, adaptar, integrar ou construir do zero.

Não reinventar uma solução madura sem registrar a justificativa. Problemas técnicos relevantes, alternativas analisadas e a decisão final devem ser materializados no Git para continuidade por qualquer IA ou desenvolvedor.

Para integrações externas, verificar também API oficial, termos da plataforma, segurança e licença antes de incorporar qualquer código.
